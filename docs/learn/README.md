# Learn how OhmWork works

Three guides to how the hardest parts of OhmWork work, each with the code to read and questions to test yourself.
Read a guide, open the files it names, then answer the questions without looking.

| Guide | You'll be able to explain |
|---|---|
| [The simulation engine](simulation-engine.md) | How a circuit becomes equations, why diodes need repeated solving, how time is simulated, and how we know the answers are right |
| [The live link](live-link.md) | How the AI agent and the learner edit one circuit at the same time, and how the link is kept safe |
| [The release pipeline](release-pipeline.md) | How a push becomes a tested website and a version tag becomes installers for every system |

Each guide ends with interview-style questions. The answers are folded under each question.
